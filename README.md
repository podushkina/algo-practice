# algo-practice

Практический репозиторий для отработки алгоритмов, структур данных и подготовки к техническим интервью (LeetCode, тренировки Яндекса и профильные контесты).

---

## Цели
- Регулярная наработка алгоритмической базы и паттернов.
- Написание чистого, идиоматичного и эффективного кода на Go с фокусом на оптимизацию времени $O(T)$ и памяти $O(M)$.
- Подготовка к алгоритмическим секциям, лайвкодингу и контестам.

---

## Структура репозитория

```text
algo-practice/
├── README.md
├── leetcode/              # Решения задач платформы LeetCode
└── yandex_trainings/      # Тренировки по алгоритмам от Яндекса 
```
